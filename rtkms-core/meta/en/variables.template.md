# Переменные и метаданные rtkms

## Области требований (категории)
- `SYS` - системные требования
- `USR` - пользовательские требования
- `FUNC` - функциональные требования
- `SEC` - требования безопасности
- `PERF` - требования производительности
- `UI` - требования интерфейса

## Модули проекта
- `CORE` - ядро
- `UI` - интерфейс пользователя
- `DB` - база данных
- `NET` - сетевое взаимодействие
- `DATA` - обработка данных
- `...` - другие модули проекта

## Этапы проекта
- `S01` - подготовительный этап (prep)
- `S02` - проектирование (design)
- `S03` - разработка ядра (core_dev)
- `S04` - разработка интерфейса (ui_dev)
- `S05` - тестирование (test)
- `...` - другие этапы проекта

## Категории знаний
- `CONCEPT` - концепции и архитектура
- `PATTERN` - шаблоны разработки
- `DECISION` - принятые решения
- `ALGO` - алгоритмы
- `TECH` - используемые технологии
- `INTEG` - интеграция с другими системами

## Статусы задач
- `backlog` - в очереди на выполнение
- `in_progress` - в работе
- `review` - на проверке
- `completed` - завершено
- `verified` - проверено
- `canceled` - отменено

## Форматы файлов
- Требования: `REQ-{категория}-{номер}` (пример: REQ-SYS-0001)
- Задачи: `TASK-{этап}-{номер}` (пример: TASK-S02-0001)
- Знания: `KN-{номер}` (пример: KN-0001)
- Код: `{имя_файла}.{расширение}`
- Документация кода: `CD-{имя_файла}`
- Диаграммы: `{тип_диаграммы}-{имя}.puml` (пример: sequence-auth.puml)

## Пути к файлам
- Требования: `${requirements_path}/{категория}/REQ-{категория}-{номер}.md`
- Задачи: `${tasks_path}/{статус}/TASK-{этап}-{номер}.md`
- Знания: `${knowledge_path}/{категория}/KN-{номер}.md`
- Документация кода: `${code_docs_path}/CD-{имя_файла}.md`
- Диаграммы: `${code_docs_path}/diagrams/{тип_диаграммы}/{тип_диаграммы}-{имя}.puml`
