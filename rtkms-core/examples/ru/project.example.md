# Система управления требованиями, задачами и знаниями "RTKMS"

## Обзор проекта
RTKMS - это система, предназначенная для управления требованиями, задачами и знаниями в проектах разработки. Она обеспечивает структурированный подход к документированию требований проекта, отслеживанию задач и управлению базой знаний.

## Цели проекта
- Создать легкую, переносимую систему управления требованиями
- Создать эффективный механизм отслеживания задач
- Сформировать структурированную базу знаний проекта
- Обеспечить интеграцию с ИИ-ассистентами
- Поддерживать создание диаграмм с помощью PlantUML

## Этапы проекта
Проект разделен на несколько этапов, каждый со своими целями и результатами. Подробная информация о каждом этапе находится в соответствующих файлах этапов и в файле `rtkms/meta/stages.md`.

### Этап 1: Основа системы
- Создать базовую архитектуру системы
- Реализовать основную функциональность
- Установить фундаментальную структуру файлов

### Этап 2: Расширенные возможности
- Реализовать расширенные механизмы отслеживания
- Разработать структуру базы знаний
- Добавить поддержку диаграмм

### Этап 3: Интеграция
- Реализовать интеграцию с ИИ-ассистентами
- Создать механизмы отчетности
- Завершить документацию

## Подход к разработке
RTKMS использует текстовый подход к управлению артефактами проекта, при котором весь контент хранится в файлах Markdown. Это обеспечивает:
- Контроль версий через Git
- Удобное редактирование с помощью любого текстового редактора
- Переносимую структуру проекта
- Кроссплатформенную совместимость

## Система управления
Этот проект использует систему управления требованиями, задачами и знаниями (RTKMS) для организации требований, отслеживания задач и управления знаниями проекта. Для получения дополнительной информации об этой системе обратитесь к каталогу `rtkms/rules`.

## Дополнительная информация
Для получения дополнительной информации об использовании системы обратитесь к файлу workflow.md и правилам в каталоге rtkms/rules.
