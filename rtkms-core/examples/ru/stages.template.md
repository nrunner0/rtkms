# Этапы проекта

## Этап 1

### Код этапа
S01

### Название
Разработка идеологии системы и базовой структуры. Первичная отладка скриптов.

### Описание этапа
Этот этап создает основу для всей будущей разработки. Основное внимание уделяется созданию прочной структуры и базовой функциональности, а не расширенным возможностям.

### Статус
in_progress

### Основные задачи
- [ ] Разработать идеологию системы для:
  - [ ] Управления требованиями
  - [ ] Управления задачами
  - [ ] Управления знаниями
- [ ] Разработать базовую структуру папок и файлов
- [ ] Разработать скрипты для инициализации работы и функционирования системы
- [ ] Произвести первичную отладку работы скриптов и файлов в среде приближенной к реальному использованию
- [ ] Определить backlog задач на следующие этапы
- [ ] Обощить опыт использования rtkms и сохранить его для применения ИИ ассистентом на следующих этапах

### Ключевые результаты
- [ ] Структура каталогов системы и базовые шаблоны для работы системы с применением ИИ ассистентов на двух языках (ru, en):
  - [ ] Система управления требованиями
  - [ ] Система управления задачами
  - [ ] Система управления знаниями
- [ ] Рабочие скрипты для инициализации работы и функционирования системы
- [ ] Backlog задач на следующие этапы
- [ ] Обобщенный опыт этапа 1
- [ ] Документация

### Список требований этапа
- [ ]  Система должна обеспечить работу ИИ ассистента на основе прозрачных и понятных правил
- [ ] Workflow выполнения этапа:
  - [ ] Изучение вариантов реализации этапа
  - [ ] Описание usecase диаграммы на языке PlantUML
  - [ ] Декомпозиция задач и их сохранение в соответствии с шаблонами и структурой папок системы
  - [ ] Определение требований для каждой задачи
  - [ ] Написание тестов для проверки (если разрабатывается ПО)
  - [ ] Написание текстов или кода по каждой задаче
  - [ ] Тестирование и отладка выполняется программно с помощью тестов и визуально пользователем
  - [ ] Написание документации
  - [ ] Сохранение методик и опыта работы для последующих этапов
