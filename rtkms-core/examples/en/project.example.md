# Knowledge and Requirements Management System "RTKMS"

## Project Overview
RTKMS is a system designed to manage requirements, tasks, and knowledge for development projects. It provides a structured approach to documenting project requirements, tracking tasks, and maintaining a knowledge base.

## Project Goals
- Create a lightweight, portable system for requirements management
- Establish an effective task tracking mechanism
- Build a structured knowledge base for the project
- Ensure seamless integration with AI assistants
- Support diagram creation with PlantUML

## Project Language
- ru (base)
- en

## Project Stages
The project is divided into several stages, each with specific goals and deliverables. Detailed information about each stage can be found in the corresponding stage files and in the `rtkms/meta/stages.md` file.

### Stage 1: System Foundation
- Create basic system architecture
- Implement core functionality
- Establish fundamental file structure

### Stage 2: Enhanced Features
- Implement advanced tracking mechanisms
- Develop knowledge base structure
- Add diagram support

### Stage 3: Integration
- Implement AI assistant integration
- Create reporting mechanisms
- Finalize documentation

## Key Project Metrics
- Number of requirements: To be tracked
- Number of tasks: To be tracked
- Number of knowledge items: To be tracked

## Development Approach
RTKMS uses a text-based approach to manage project artifacts, with all content stored in Markdown files. This enables:
- Version control through Git
- Easy editing with any text editor
- Portable project structure
- Cross-platform compatibility

## Management System
This project utilizes the Requirements, Tasks and Knowledge Management System (RTKMS) to organize requirements, track tasks, and maintain project knowledge. For more details on this system, refer to the `rtkms/rules` directory.

## Additional Information
For more details on using the system, refer to the workflow.md file and the rules in rtkms/rules directory.
